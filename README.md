# Anatomy Explorer

An educational, interactive 3D human anatomy explorer built with React and Three.js. Developed for **COMPX241 - Smoke & Mirrors** at the University of Waikato.

## Live Demo

Deployed on Vercel: **[anatomyexplorer.vercel.app](https://anatomyexplorer.vercel.app)**

## Run Locally

**Requirements:** Node.js 18+

```bash
git clone https://github.com/wchernandez/Anatomy-Explorer.git
cd Anatomy-Explorer
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.
